TradeSphere System Architecture

Core Workflow: User Interface → Flask API Gateway → Authentication → Order Management → Validation → Matching Engine → Trade Execution → Portfolio Service → SQLite Database → Audit Logs → Notification.

Viva Key Points

  • Matching Engine: Matches buy and sell orders using price-time priority.
  • Consistency: Trade execution updates order, balance, portfolio, trade, and audit records together.
  • Scalability: In real systems, Kafka, Redis, WebSocket, and distributed matching engines are used.
